# Kịch bản kiểm thử API bằng Karate Framework — 55 TC

Phạm vi: Mục 3.1.2 (8 nhóm API). Ghi chú chung: fixture tạo tài khoản qua `POST /admin/users/api` nên `username` sinh viên là mã 8 chữ số tự sinh (`<studentA.username>`); token truyền qua header `Authorization: Bearer <token>`; các message lỗi trong bảng đã đối chiếu chính xác với source code; case OAuth2 positive cần code Google thật nên chuyển thành negative + kiểm thử thủ công.
